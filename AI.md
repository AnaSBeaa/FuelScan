#Documentação do Uso de Inteligência Artificial

## 1. Ferramentas utilizadas

Durante o desenvolvimento do projeto, foram utilizadas duas ferramentas de Inteligência Artificial como recursos de apoio técnico:

### ChatGPT

Utilizado como ferramenta de aprendizado e orientação técnica para compreender como aplicar e integrar a MockAPI ao site do projeto do sensor de nível de combustível. Foi utilizado para esclarecer dúvidas sobre o funcionamento da API, entender como realizar sua integração e obter orientações sobre as alterações necessárias no código para utilizar os dados disponibilizados.

### Claude

Utilizado como apoio na identificação e resolução de erros no código-fonte. Sua principal aplicação ocorreu durante uma alteração na nomenclatura de chaves utilizadas no projeto, quando algumas referências não foram atualizadas corretamente em todos os pontos do código, ocasionando erros de funcionamento.

## 2. Interações realizadas

As interações com as ferramentas ocorreram por meio de prompts relacionados a dúvidas técnicas e problemas específicos encontrados durante o desenvolvimento.

### ChatGPT — Orientação sobre a aplicação da MockAPI

**Exemplo de prompt:**

> Estou desenvolvendo um site para um projeto de sensor de nível de combustível e preciso utilizar a MockAPI para disponibilizar e consumir os dados no site. Você pode me explicar como funciona essa integração, como realizar as requisições à API e quais alterações preciso fazer no código para utilizar os dados retornados?

**Resposta obtida:** explicações sobre o funcionamento da MockAPI, orientações sobre a realização de requisições e exemplos de como integrar os dados retornados pela API aos componentes do site.

### Claude — Identificação e correção de erros no código

**Exemplo de prompt:**

> Realizei a renomeação de algumas chaves no código, mas estou recebendo erros porque aparentemente nem todas as referências foram atualizadas corretamente. Analise o código e me ajude a identificar onde estão as referências antigas e quais alterações precisam ser feitas para corrigir o problema.

**Resposta obtida:** orientações para localizar as referências que ainda utilizavam a nomenclatura anterior, identificar inconsistências e realizar as correções necessárias nos diferentes pontos do código.


## 3. Aplicação no projeto

As ferramentas de Inteligência Artificial foram utilizadas como apoio em atividades específicas, sem substituir o desenvolvimento realizado pelo grupo.

As principais aplicações foram:

- **Integração da MockAPI:** utilização do ChatGPT para compreender como utilizar a MockAPI no projeto, realizar requisições e integrar os dados disponibilizados pela API ao site.
- **Orientação sobre o código:** utilização do ChatGPT para esclarecer dúvidas sobre a implementação da integração e compreender as alterações necessárias para o funcionamento da comunicação com a API.
- **Correção de nomenclatura de chaves:** utilização do Claude para identificar referências que não haviam sido atualizadas após a renomeação de chaves, auxiliando na localização e correção das inconsistências.
- **Resolução de problemas:** utilização do Claude para analisar erros encontrados durante o desenvolvimento e obter sugestões de correção.


## 4. Validação das respostas

As respostas fornecidas pelas ferramentas de Inteligência Artificial foram utilizadas como orientação e passaram por validação prática no próprio código do projeto.

A validação ocorreu por meio da aplicação das alterações sugeridas, seguida de testes para verificar se as funcionalidades apresentavam o comportamento esperado.

No caso da integração da MockAPI, as orientações foram utilizadas para realizar as alterações necessárias no código e verificar se a comunicação com a API e a utilização dos dados estavam funcionando corretamente.

No caso das correções sugeridas pelo Claude, foram realizadas alterações nas referências das chaves e testes para verificar se os erros decorrentes da renomeação haviam sido solucionados.

Dessa forma, as sugestões não foram consideradas soluções definitivas sem verificação, sendo necessário analisar, modificar e testar o código para confirmar sua compatibilidade com o projeto.

## 5. Análise crítica

A utilização das ferramentas de Inteligência Artificial trouxe benefícios ao desenvolvimento do projeto, principalmente por facilitar o aprendizado de novas tecnologias, esclarecer dúvidas técnicas e auxiliar na resolução de problemas encontrados durante a programação.

O ChatGPT contribuiu principalmente para a compreensão e aplicação da MockAPI, permitindo entender melhor como realizar a integração e utilizar os dados disponibilizados pela ferramenta. Já o Claude foi útil na identificação de inconsistências no código, especialmente em situações nas quais alterações de nomenclatura precisavam ser atualizadas em diferentes partes do projeto.

Entretanto, foi necessário avaliar as respostas recebidas, pois as ferramentas podem apresentar sugestões que precisam ser adaptadas à estrutura e às particularidades do código existente. Por isso, a utilização da IA não dispensou o entendimento das alterações realizadas nem os testes necessários para verificar seu funcionamento.

Conclui-se que as ferramentas de Inteligência Artificial foram recursos complementares importantes, contribuindo para o aprendizado, a otimização de algumas etapas do desenvolvimento e a resolução de problemas técnicos, sem substituir o conhecimento, as decisões e o trabalho de implementação realizados pelos integrantes do grupo.
